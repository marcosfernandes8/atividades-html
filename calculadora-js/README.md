# Calculadora em HTML, CSS e JavaScript

Criei uma calculadora simples utilizando HTML, CSS e JavaScript.

O usuário informa dois números nos campos de entrada e seleciona a operação desejada através dos botões disponíveis na interface.

## Implementação

A estrutura da página foi criada com HTML, contendo:

- Dois campos para inserção dos números.
- Quatro botões para as operações matemáticas.
- Uma área para exibição do resultado.

O CSS foi utilizado para organizar e estilizar a interface da calculadora.

No JavaScript foram criadas quatro funções:

### Soma

```javascript
let resultado = num1 + num2;
```

### Subtração

```javascript
let resultado = num1 - num2;
```

### Multiplicação

```javascript
let resultado = num1 * num2;
```

### Divisão

```javascript
let resultado = num1 / num2;
```

Cada função captura os valores digitados pelo usuário, realiza o cálculo correspondente e exibe o resultado na tela.
